# Paired balance evidence

Stage: discovery. Positive differences favor baseline access. Each pair uses the same setup seed, lineup and seats. Both arms use separately trained profiles with equal search budgets. One declared restriction changes. Effects measure access value under the declared policy search, not intrinsic card/event strength or an optimized rule change.

Primary comparison family: 1 player-count × restriction cells, declared before play. Intervals bootstrap whole seed blocks (20,000 resamples); adjusted intervals use Bonferroni alpha = 0.05 / 1. These are approximate bootstrap intervals. Seed blocks with either arm failing are excluded as a whole from that cell; any such exclusion blocks a positive evidence classification. Low exposure (<10%) and fewer than 20 blocks remain inconclusive. No equivalence claim is made.
